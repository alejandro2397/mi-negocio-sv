Mi Negocio SV - funciones incluidas

- Registro de productos
- Registro de ventas
- Unidades: unidad, libra, arroba, quintal y saco
- Costo, precio de venta, ganancia y margen
- Precio recomendado por margen deseado
- Calculadora de papa por quintal y libras
- Comprobante PDF
- Compartir comprobante PDF mediante Android

Nota: el escaneo de facturas con IA requiere una integración adicional y no se activa en esta versión para mantener la compilación estable.
